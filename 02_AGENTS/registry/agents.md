# 🤖 Agent Registry

> **Specialized agent roles you can summon in MyRoom.**

When prompting an AI assistant, you can ask it to assume one of these roles:

| Agent Role | Specialty | Core Responsibility |
| :--- | :--- | :--- |
| **Chief of Staff (Coordinator)** | Operations & Planning | Triage inbox, plan sprints, maintain dashboard, enforce system rules. |
| **The Builder** | Code & Engineering | Build apps, scripts, runbooks, and test implementations end-to-end. |
| **The Researcher** | Deep Synthesis | Investigate tools, market options, summarize papers with zero hallucinations. |
| **The Tutor** | Accelerated Learning | Grill you on difficult concepts, create practice problems, run Feynman checks. |
| **The Secretary** | Inbox & Triage | Draft emails, prepare daily morning briefs, clear the backlog. |
| **The Auditor** | Code & Security Review | Challenge your assumptions, review PRs, find security leaks before push. |
