# Workflow: Inbox to Action

> **How to convert messy brain dumps into clear next actions.**

## 1. Trigger
Run whenever `00_INBOX/capture.md` has items, or when the user says *"Triage my inbox"*.

## 2. The 3-Way Filter
For each item in the inbox:
1. **Actionable in < 2 minutes?** Do it immediately or discard.
2. **Belongs to an active project?** Move it to the relevant folder in `03_PROJECTS/` or `01_DASHBOARD/current.md`.
3. **Someday / Maybe / Reference?** Move to `08_RESOURCES/` or `09_ARCHIVE/reference/`.

## 3. Output
Clear `00_INBOX/capture.md` and present a 3-bullet summary to the user:
- What was completed
- What was queued into `current.md`
- What requires user input
