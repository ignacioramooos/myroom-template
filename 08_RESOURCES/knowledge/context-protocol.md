# Protocolo de contexto

Este protocolo ayuda a que agentes futuros trabajen sin perder informacion.

## Antes de trabajar

Leer:

1. `README.md`
2. `AGENTS.md`
3. `01_DASHBOARD/current.md`
4. `01_DASHBOARD/operating-system.md`
5. `08_RESOURCES/knowledge/user-operating-profile.md`
6. Carpeta de tarea relevante en `02_AGENTS/tasks/`, si existe
7. README del area relevante
8. Archivo especifico del proyecto, tramite, curso o automatizacion
9. Si hay delegacion agentica, `10_SECRETARIAT/operating-manual.md`

## Durante el trabajo

Registrar:

- objetivo
- supuestos
- decisiones
- cambios realizados
- evidencia de verificacion
- bloqueos
- carpeta de tarea donde quedara el expediente
- aprendizajes reutilizables para futuros agentes

## Despues del trabajo

Actualizar:

- `02_AGENTS/tasks/YYYY-MM-DD-slug/record.md`
- `08_RESOURCES/knowledge/` si hubo aprendizaje estable o reutilizable
- archivo principal del tema
- dashboard si cambia el estado general
- log del agente si hubo una decision o avance importante
- runbook si se creo o modifico una automatizacion
- cola del secretariado si el trabajo fue delegado
- `12_PROJECT_NETWORK/` si se modifico o investigo otro proyecto
- ejecutar `02_AGENTS/workflows/continuous-improvement.md`
